# Sales call prep

## Steps

1. Confirm the account name and the goal of the call. Ask if either is missing.
2. Find what the Library holds on the account. Search matches file names, so try the account name, "notes", "proposal" or "contract", or list the Library with no query.
3. Read the most relevant documents: past call notes, proposals, contracts, support history.
4. Write the brief.

## Brief format

- **Account**: who they are, in 2 sentences.
- **Relationship so far**: key dates, what they bought or were offered, current status.
- **People**: names and roles as written in the documents.
- **Goal for this call**: what a good outcome looks like.
- **Talking points**: 3–5 bullets tied to their known needs.
- **Risks and open questions**: objections raised before, unresolved issues.
- **Sources**: the file names used.

## Rules

- Keep it to one page.
- Use only what the documents and the user say. Never invent contacts, figures or history; write "not in the Library" instead.
- Flag documents that look out of date.
