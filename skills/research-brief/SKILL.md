# Research brief

## Steps

1. Find candidate documents. Library search matches file names, not contents, so search for 2–4 words likely to appear in a file name. If that finds nothing useful, search with no query to list the Library and pick from the names.
2. Read the most relevant documents.
3. Write the brief.

## Brief format

- **Answer**: the direct answer in 1–3 sentences.
- **Key findings**: bullets, each ending with its source document name.
- **Gaps**: what the Library doesn't cover or where documents disagree.

## Rules

- Every claim needs a source from the Library. If nothing supports it, leave it out or list it under Gaps.
- Prefer recent documents when sources conflict, and say that you did.
