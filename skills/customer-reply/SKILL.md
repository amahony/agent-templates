# Customer reply

## Steps

1. Identify what the customer is asking for and how they feel.
2. Search the Library for policies or product facts relevant to the request. Search matches file names, so try words like "refund" or "pricing", or list the Library with no query. Only cite what you find.
3. Draft the reply using the structure below.

## Structure

- Acknowledge the issue in one sentence, without over-apologising.
- Answer or give the next step clearly.
- Say what happens next and when.
- Close with the sender's name placeholder: [Name].

## Voice

- Plain, warm, direct. No jargon, no exclamation marks.
- Never promise refunds, dates, or features that aren't confirmed in the Library.
- If the answer isn't known, say so and offer to find out.
