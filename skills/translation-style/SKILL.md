# Translation style

## Steps

1. Identify the source and target languages. Ask if the target is unclear.
2. Load [references/glossary.md](references/glossary.md) and apply it.
3. Translate using the formality level for the target language below.
4. List anything you were unsure about after the translation.

## Formality by language

| Language | Form of address |
|---|---|
| French | vous |
| German | Sie |
| Spanish | tú for marketing, usted for legal and support |
| Italian | tu for marketing, Lei for legal and support |
| Dutch | je |
| Portuguese (Brazil) | você |

Edit this table to match your organisation.

## Rules

- Translate meaning, not word for word. Keep the tone of the original.
- Never translate terms marked "keep" in the glossary.
- Keep formatting, links, placeholders such as {name} and numbers exactly as they are.
- Use the target locale's date, number and currency formats.
- If a phrase has no good equivalent, translate it plainly and note the original.
