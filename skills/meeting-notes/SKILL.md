# Meeting notes

## Output format

1. **Summary**: 2–3 sentences on the purpose and outcome.
2. **Decisions**: one bullet per decision, stated as a fact.
3. **Action items**: a table with Owner | Task | Due date. Write "Unassigned" when no owner was named.
4. **Open questions**: anything raised but not resolved.

## Rules

- Use only what the notes say. Never invent owners or dates.
- Use names as written in the notes.
- Leave out small talk and repeated points.
- If the notes are ambiguous about a decision, list it under Open questions.
